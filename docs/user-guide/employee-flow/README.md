## 发现的问题

### 已修复（PR #17，部署 #86，2026-10-28 复测通过）

1. 文件签署时间少 8 小时：`backend/src/models/Employee.js` 用 `toISOString()` 输出 UTC 时间，
   员工 A 实际在北京时间 11:05 签署，页面显示 03:05。改为北京时间输出。
2. 考勤报表只读打卡机汇总，系统内批准的请假不计入。改为结合两者：
   - 请假天数取打卡机与系统请假中较大的一个；打卡机不知道的请假不再算旷工
   - 已请假但当天有打卡：标为考勤异常
   - 未请假、工作日也没有打卡：列为旷工提醒
   - 报表页新增“考勤提醒”卡片，导入打卡的结果弹窗也列出这两类提醒
3. 请假列表默认只显示近期请假日期的记录，补请以前日期的假提交后看不到。改为默认不按日期筛选。
4. 请假通知中请假类型显示英文代码（“类型：personal”）。改为显示中文。

说明：请假列表“申请日期”和通知时间按浏览器所在时区显示，测试电脑不在国内才显示为 10-22，
国内电脑显示正确，不算缺陷。

### 需要确认或改进

5. 承诺函模板中的培训名称（医疗器械检(化)验员培训班）和培训结束日期（2026年3月20日）是固定写死的，
   HR 配置界面无法修改，所有员工的承诺函内容相同。
6. 员工签署后，HR 仍可点击“修改信息”更改已签署承诺函的费用和年限。
7. 系统没有“发送承诺函”操作，也不发通知；HR 配置后员工需要自己进入“制度确认”查看。
8. 员工请假页“申请请假”按钮在两张图表下方，需要向下滚动很远；“天数”不按日期自动计算。
9. 员工端右上角显示工号而不是姓名；签署一次约需 10 秒。
