## USER-04 界面文案语言

- 观察：搜索框和筛选框的占位文字是英文（“Search username/name”“Filter by role”“Filter by status”），表格空状态是“No data”，分页是“10 / page”，日期选择器是“Select date”“Start date”。报销审核确认框的按钮也是“Cancel / OK”
