- 结果：通过

## SS-02 添加社保记录

- 步骤：点“添加记录”
- 预期：打开新增表单
- 实际：地址变成 `/social-security/new` 后立刻跳回“系统概览”，无法手工新增
- 结果：**失败**
- 原因：按钮跳转到 `/social-security/new`（`frontend/src/pages/SocialSecurity/SocialSecurityList.tsx:325`），但 `App.tsx` 只注册了 `social-security` 列表路由，没有新增页，未匹配的地址被兜底规则重定向到 `/dashboard`
- 建议：补上新增/编辑页和路由；如果暂时只支持导入，就先隐藏这个按钮

![跳回系统概览](screenshots/ss-02-add-redirects-dashboard.jpg)

## SS-03 社保 Excel 导入与金额合计

- 文件：按 `sample_data/社保公积金导入模板.xlsx` 的表头做了一行测试数据：QA-0001，2026-10，社保和公积金基数都是 5000，养老 400/800、医疗 100/500、失业 25/50、工伤 40、生育 40、公积金 600/600
- 注意：`CommunicationDocs/BusinessData/花名册Splits/保险.xlsx` 是 HR 手工记的缴纳备注（姓名、转正日期、“10.6之前”这类文字），不是导入模板格式，不能直接导入
- 预期：个人合计 400+100+25+600 = 1125；公司合计 800+500+50+40+40+600 = 2030
- 实际：提示“导入完成：成功 1 条”，列表显示个人合计 ¥1125.00、公司合计 ¥2030.00、已缴纳、2026-10-15
- 结果：通过
