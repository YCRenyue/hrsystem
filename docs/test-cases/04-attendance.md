## ATT-05 导入数据与源表核对

用源文件“汇总表”工作表抽查 4 人：

| 姓名 | 源表实际出勤/旷工 | 系统 上班/旷工 | 源表假日加班 | 系统假日加班 |
|------|------|------|------|------|
| 祝青 | 16/14，旷工 2 | 14 / 2 | 40.07 | **40.70** |
| 许君君 | 16/0，旷工 16 | 0 / 16 | 0 | 0.00 |
| 苏芹 | 16/0，旷工 16 | 0 / 16 | 70.15 | 70.15 |
| 陆立兄 | 16/0，旷工 16 | 0 / 16 | 46.59 | 46.59 |

- 结论：上班和旷工天数与源表一致；祝青的假日加班源表是 40.07，系统是 40.70，疑似按刷卡明细重新计算，或者小数位处理有误，需要 HR 用原始打卡核实
- 观察：生产部很多人源表显示“实际出勤 0、旷工 16”，同时又有 40 到 70 小时的假日加班。这是考勤机排班设置导致的（倒班人员没排班），系统忠实导入了源数据。HR 使用前需要先在考勤机里修正排班，否则报表会显示大量旷工
